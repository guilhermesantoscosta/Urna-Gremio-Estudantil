# Urna Eletrônica para Grêmio Estudantil

Uma simulação de urna eletrônica desenvolvida para eleições de grêmio escolar, com design inspirado na urna brasileira e funcionalidades completas.

## ✨ Funcionalidades

- Interface com display grande e teclado numérico
- Cadastro de chapas com foto, nome e número
- Modo administrador com senha configurável (código 99)
- Painel do professor em janela separada para liberação de votos (senha configurável)
- Sons realistas (tecla, confirmação estilo "Pi-ri-li-ri-liiiii", branco, liberação)
- Reinicialização e encerramento da votação com geração de imagem dos resultados
- Salvamento/carregamento da configuração no localStorage

## 🚀 Como usar

1. Clone o repositório
2. Abra o arquivo `index.html` no navegador
3. Para votar: digite o número da chapa (2 dígitos) e confirme
4. Para administrador: digite `99` e a senha (padrão: `ProfProf`)
5. No painel admin, abra o "Painel do Professor" para liberar votos

## 📝 Configuração de senhas

As senhas podem ser alteradas no painel administrativo:
- **Senha de liberação**: usada no painel do professor
- **Senha de admin**: usada para acessar o painel
